# Currency Converter

A simple currency converter built using HTML, CSS, and JavaScript.

## Features

- Convert between supported currencies
- Fetch current exchange rates from the Frankfurter API
- Swap currencies
- Input validation
- Loading and error handling
- Responsive design

## Technologies

- HTML
- CSS
- JavaScript
- Fetch API
- Frankfurter API

## How to Run

Open `index.html` in a web browser.
